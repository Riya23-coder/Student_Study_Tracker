# Student Study Tracker 📚

## About the Project
Student Study Tracker is a beginner-friendly Python project that helps students record and monitor their daily study activities. I built this project to improve my Python programming skills and develop practical projects as I work toward becoming an AI engineer.

## Features
- Add a study session with a subject and topic.
- Record study duration in minutes.
- Record what I learned during each session.
- View all recorded study sessions.
- Calculate daily study time and progress toward a daily goal.
- Set a daily study-time goal.
- Handle invalid user input.

## Technologies Used
- Python
- Python standard library (`datetime`)

## How to Run the Project

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

   ```bash
   python main.py
   ```

   On Windows, if that command doesn't work, try:

   ```bash
   py main.py
   ```
